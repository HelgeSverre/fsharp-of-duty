No engine.
No assets.
No art pipeline.

04 // TECHNOLOGY

How it works.

01

Procedural content

Maps, meshes, materials, audio, fonts, and particles are generated deterministically from code — the repository contains no binary game assets.

02

Deterministic simulation

A fixed 60 Hz functional core with an imperative shell. The same gameplay code drives offline play, the bots, and the server.

03

Authoritative netcode

Client-side prediction, interpolation, reconciliation, and lag-compensated hit detection over WebSockets. The server recomputes everything.

04

Full combat model

ADS, sprinting, stances, recoil, grenades, material penetration, and per-projectile ballistics resolved on the server.

05

Bots that navigate

A generated navigation graph with A* pathfinding, cover behavior, and suppression drives the offline opposition.

06

Cross-platform

Self-contained installers for Windows, macOS (universal), and Debian, plus plain archives. No runtime to install.
